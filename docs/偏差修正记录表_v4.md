## 三、红线约束（逐字保留，v4.0.0 未放松任何一条）

- 清华大学数据规范；不对导师做人格层面主观评判；
- 不编造联系方式/招生名额/主页；知识库未收录 → 「该信息暂未收录：暂无「{name}」的公开评价综述，
  建议通过官方邮箱联系导师确认。」；
- 诚实空态（不画「基准 50」）；LLM 失败完全降级回固定模板；
- 六维主观评分 ≥8 样本门控（`ADVISOR_RATING_MIN_SAMPLES=8`）；popularity 是 D1 禁止字段；
  sector 被治理剥离；
- 雷达图分离客观与主观；方向地图只输出学科方向本身，不输出参考教师名单；
- 知识库只入综述级、无原始引文、可溯源（SHA256 清单），回复带
  「公开存档匿名主观评价聚合，仅作参考，不构成对导师能力的客观评判」声明；
- 记忆只写白名单事实（已确认画像维度 + 确认门标记）；匹配/确认门永不由 LLM 决策；
- 无 key / 无索引全链路降级现行为。
