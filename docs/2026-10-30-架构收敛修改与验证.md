# 架构收敛修改版与验证

日期：2026-10-30。基于当前工作区继续修改，保留已有模拟模式改动；本记录不代表远程发布或生产验收。

## 本版目标

保留 Web / 清小搭双入口共享业务内核，将本地演示、前端状态与后端领域规则对齐。外部模型 API 和正式导师库继续作为后续接入项，本版使用规则访谈与三条明确标注的合成导师。

## 修改内容

### 运行入口

- `backend/.env.example` 可直接用于本地规则、合成导师、SQLite、本地私有文件演示；不再默认要求 S3 或模型密钥。
- 空 `LLM_PROVIDER` 规范为未配置。非 DEBUG / 正式部署禁止模拟导师；正式治理文件缺失不会静默退回空数据。
- 根 Compose 定位为本地集成，修正 psycopg v3 URL，挂载只读导师种子，增加先迁移后启动顺序；生产仍使用专用 RUNBOOK。
- 中文 PDF 字体选择验证 TrueType 可嵌入性与中文字形，支持本机 macOS 字体；配置方法见 README。
- A7 彩排使用隔离的本地资源，不被开发 `.env`、模型凭据或模拟导师开关影响。

### 前端状态与产品契约

- 匹配编排由聊天组件移到 store，结果绑定会话、画像版本和请求编号；跨路由保留，新会话或画像变更使旧请求失效。
- 匹配和公开散点分别管理 loading，匹配失败提供显式重试。
- 聊天、画像编辑和确认的晚响应不会恢复旧会话；主动取消不弹错误提示。
- 明确拒绝的 422 输入保留在页面并标注，但不再重放到后续历史；网络失败仍保留用户历史供服务端恢复同步。
- 导师选择、对比和点赞使用稳定 ID；同名导师不会被当成同一条记录。
- 右侧主面板显示实际六目标分解、保守贡献、证据和待核实问题。移除无效的旧六维权重滑块；公开分布图不再补出“契合度 50”。
- 个人页明确为简历资料。科研经历使用一个保存后的权威输入，GPA 和科研经历实际进入生成请求；编辑副本与已保存资料不共享数组。
- 独立前端 Mock 跳过私有会话请求，导师库与招募列表可展示空态；私有文件和发布入口明确不可用，不制造提交成功。
- 调整顶部运行提示占用的布局空间，并为移动端复用匹配依据面板、提供可访问的对话展开按钮。

### 后端正确性

- 保守排序总分汇总各维未四舍五入的保守贡献，避免跨维借用置信度。
- 利用已有 `profile_version` 加入数据库乐观锁，回答、编辑、确认的并发冲突返回 409，无新增 schema 迁移。
- 长回答的衍生字段超限返回 422，拒绝该轮时不修改画像、不消费用户回答。
- 招募公开展示与投递共享审核、发布、下架、截止日期和过期时间规则。日期按上海时区包含当天，时间戳到点失效。
- 投递按“文档 → 招募”顺序加锁，并在锁等待后重新校验招募；目标数据库招募使用主键查询和行锁，保持至提交。SQLite 使用已有立即事务机制。

## 如何体验和复查

按 README 的本地开发步骤启动。已有 `.env` 不会被覆盖，如需本版演示配置，请核对 `LLM_ENABLED=false`、`ALLOW_SIMULATION_MENTORS=true`、`OBJECT_STORE_BACKEND=local` 与本地数据库地址。

```bash
# 在 backend/，激活虚拟环境后
python -m pytest -q

# 在 frontend/
npm run lint
npm run test:state
npm run build
```

状态测试使用真实 Pinia store 与受控 API 响应，覆盖运输层忽略取消时的旧响应回写，而非只检查实现字符串。
