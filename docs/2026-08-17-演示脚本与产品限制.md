# Tsing-RADAR 2026-08-17 演示脚本与产品限制

## 五分钟演示脚本

1. 打开 Web 首页，说明当前候选不内置导师记录，页面只展示经过发布审核的数据。
2. 创建一次访谈，用 3–5 轮回答说明研究方向、指导风格和硬约束。
3. 打开画像卡片，编辑一项内容并逐项确认硬约束，最后确认画像。
4. 在确认前尝试匹配，展示服务端拒绝；确认后重新匹配。
5. 若资料库仍在审核，展示“尚无已审核导师数据”的诚实空结果，说明这只是发布前安全状态，不是 Tier A 验收结果；不会生成虚假导师、主观评分或“成功匹配 N 位”文案。
6. 调用清小搭兼容文本接口：先验证 `GET /v1/models`，再分别进行一次 JSON 与 SSE 对话，并演示携带完整消息历史的后续一轮。
7. 最后说明当前未启用能力以及真实 LLM、域名/TLS、附件/COS 的实际验收状态，不把本地规则模式或未配置资源说成生产能力。

## 产品限制与诚实边界

- **导师数据**：资料库通过来源、授权、字段质量和发布审核前保持 0 条安全状态。审核失败、无授权或受限记录不会进入公开 API 或匹配。2026-08-17 目标固定为 Tier A；若届时没有至少一批通过审核并可发布的真实导师记录，交付状态必须是 `BLOCKED`，不得用 0 条数据冒充 Tier A。
- **LLM**：生产接口固定为 `LLM_PROVIDER=<glm|deepseek>` 与只读文件 `/run/secrets/llm_api_key`。没有真实、获授权的 provider Key 时只运行本地规则模式，不宣称真模型交付。
- **清小搭身份**：平台没有稳定且可验证的终端用户 claim 时，只依据本次请求携带的完整文本历史重建访谈；不提供跨设备长期身份，也不把 IP、UA、API Key 或固定 anonymous 当作用户身份。
- **附件与 COS**：香港生产目标固定使用私有 `ap-hongkong` COS、bucket-free regional endpoint、virtual-hosted style 与 AES256。真实桶、最小权限和端到端验收完成前保持关闭；文本响应明确说明“未启用”，不返回伪造下载地址。
- **legacy**：旧应用只用于代码对照，导师数据固定为空；它不会读取或恢复已删除的导师文件。
- **Git 历史**：旧数据已从当前版本删除，但历史未改写。这是已接受的残余风险，不得表述为历史已清理。
- **公网状态**：只有域名、适用的 ICP/地域合规、TLS 和公开面验收真实通过后才能声明正式上线；内部部署通过不等于公网生产可用。正式公网只允许 Web/QXD 所需的 TCP 80/443，SSH 始终限制可信来源。
