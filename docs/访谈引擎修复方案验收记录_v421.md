## 五、未改动红线（逐字保留）

- 画像确认门（needs_confirmation）与匹配结果（recommend_ready）不进表达层；
- LLM 失败/无凭据完全降级回固定模板；诚实空态（不画「基准 50」）；
- 六维主观评分 ≥8 样本门控；popularity 是 D1 禁止字段；sector 被治理剥离；
- 匹配/确认门永不由 LLM 决策；legacy 内部路由 `/api/v1/llm/chat`（llm.py）保持
  既有增强行为不变（修复5 仅作用于 QXD 外部网关 `/v1/chat/completions`）。
